# Archive

This directory stores archived, deprecated, and unused assets, prototypes, and scratch files moved out of active working directories (`plans/`, `public/`, and the repository root) to keep the project clean while preserving assets.

## Directory Structure

### `ai-context/`
- **`fun-project/`**: Standalone HTML/JS YouTube lesson player prototype (`index.html`, `script.js`, `styles.css`, `LICENSE`).
- **`me-temp/`**: Temporary scratch notes from earlier phases (`phase_2_auth.md`, `phase_3_courses_cohorts.md`, `phase_4_5_mongodb_workspace.md`, `phase_6_migration_pattern.md`).
- **`logos/`**: Draft and alternate SVG logo exports (`LOGO-recolored*.svg`, `LOGO-no-book-compass.svg`).

### `public/`
- **`boilerplate/`**: Leftover default Next.js starter icons (`file.svg`, `globe.svg`, `window.svg`).
- **`icons/`**: Unused reference icon graphics (`icon-style-ref.png`, `screenshotquill.png`).
- **`images/`**: Unused mascot and promotional illustrations (`footer-mascot.png`, `onlyMascot.png`, `clouds.webp`, `dashboard-microlearning.png`).
- **`mock-thumbnails/`**: Unused mock media covers (`civilization.jpeg`, `data-storytelling.jpg`, `deep-work-m.png`, `history-psych.jpg`, `philosophy.jpg`, `reading.webp`, `space.jpeg`).
- **`logos/`**: Previous SideQuestHQ brand logos (`sidequesthq-logo.svg`, `sidequesthq-logo-no-book-compass.svg`, `floating-logo.svg`, `old-favicon.ico`).

### `misc/`
- **`test_iframe.html`**: Test iframe snippet.
- **`render.yaml.disabled`**: Disabled Render cloud service configuration.
- **`scratch.txt`**: Empty scratchpad from `src/server/infrastructure/external/`.
